Dataset Availability

The original DataCo Smart Supply Chain dataset is not included in this repository because its file size exceeds the recommended limit for files stored directly in a Git repository.

To keep the repository lightweight and make the project easier to clone and download, the dataset is hosted externally on Kaggle.

Dataset Overview

Records: 180,519 order line items

Columns: 53

Date Coverage: 2015 – January 2018

Geographic Coverage: 164 countries

Distinct Orders: 65,752

Distinct Products: 118

Download Instructions

Download the dataset from Kaggle:

DataCo Smart Supply Chain Dataset

After downloading, place DataCoSupplyChainDataset.csv inside the Dataset/ folder in this repository before running the Python notebook or importing the data into MySQL.

Note: GitHub's standard Git repository workflow warns about files larger than 50 MB and generally blocks files larger than 100 MB. Git Large File Storage (Git LFS) is an alternative for managing larger files.
